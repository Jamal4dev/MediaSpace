# MediaSpace

MediaSpace is a beginner-level Django multimedia website built for the Bincom Academy Python Beginners Class. It is a simple gallery application that stores and displays image, video, and audio content using Django's built-in admin interface and SQLite database.

## Project overview

This project is a small web application for browsing a multimedia collection. The home page shows the latest media items, while separate pages display images, videos, and audio files. The project is designed as a learning example for Django fundamentals such as models, templates, URL routing, admin registration, file uploads, and static CSS styling.

The application is a local development project and is not deployed to a public server.

## Project objectives

The main goals of this project are to:

- learn how to create a Django project and app
- model a database table for media content
- store uploaded files in the project media folder
- display media content in templates using Django views
- organise content by image, video, and audio categories
- use the Django admin dashboard to manage records
- apply simple front-end styling with custom CSS

## How the multimedia upload system works

The multimedia upload system is implemented using the `MediaItem` model in `gallery/models.py`.

### Model structure

The model contains the following fields:

- `title` — the title of the media item
- `description` — a short description
- `media_type` — one of `Image`, `Video`, or `Audio`
- `file` — the uploaded file, saved using `FileField(upload_to='media_files/')`
- `date_added` — the date when the item was created

### File upload behavior

When an administrator creates a new `MediaItem` in Django admin:

1. They choose the media type.
2. They upload a file.
3. The file is saved to the project `media/media_files/` directory.
4. The `file` field stores the uploaded file path.
5. The file is displayed in the templates using the URL generated by Django.

### Validation rules

The `clean()` method validates the file extension based on the selected `media_type`:

- Images: `.jpg`, `.jpeg`, `.png`, `.gif`, `.webp`
- Videos: `.mp4`, `.webm`, `.ogg`
- Audio: `.mp3`, `.wav`, `.ogg`, `.m4a`

If the chosen file extension does not match the selected media category, Django raises a validation error and the record is not accepted.

### Important note

This project does not include a public web form for uploading media. Uploading is done through the Django admin interface, which is the actual implementation present in the code.

## Django administration dashboard

The project uses Django's built-in administration system to manage the media collection.

### Admin registration

The admin configuration is defined in `gallery/admin.py`.

The `MediaItemAdmin` class includes:

- `list_display = ('title', 'media_type', 'date_added')`
- `list_filter = ('media_type', 'date_added')`
- `search_fields = ('title', 'description')`
- `ordering = ('-date_added',)`

This makes the admin dashboard useful for:

- adding new media entries
- filtering records by media type
- searching by title or description
- viewing new items first

### Accessing admin

After creating a superuser, open the Django admin at:

- `http://127.0.0.1:8000/admin/`

## Installation requirements

Before installing the project, ensure the following are available on your Ubuntu/Linux system:

- Python 3.10 or newer
- `pip` for Python package installation
- `venv` support for creating a virtual environment
- Internet access to install Django

## Step-by-step installation instructions for Ubuntu/Linux

Open a terminal and run the following commands:

```bash
cd /home/jamal/projects/MediaSpace
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install django==6.1.1
```

### Notes

- `python3 -m venv .venv` creates a project-local virtual environment.
- `source .venv/bin/activate` activates it for the current terminal session.
- The project was generated using Django 6.1.1, so this version is used for consistency.

## Activating the virtual environment

After the environment is created, activate it whenever you work on the project:

```bash
cd /home/jamal/projects/MediaSpace
source .venv/bin/activate
```

When the virtual environment is active, your terminal prompt usually changes and `python` points to the environment's Python interpreter.

If Django is not yet installed in the virtual environment, install it with:


## Project limitations and future improvements

The current project is intentionally simple and beginner-friendly, but it has some limitations:

- there is no public user upload form; media is managed by Django admin only
- there is no registration/login system for regular users
- there is no file size validation, MIME validation, or antivirus scanning
- there is no pagination for large media collections
- there is no search or filter bar on the frontend pages
- there is no image thumbnail generation or automatic resizing
- there is no deployment setup for a production environment

Possible future improvements include:

- adding a user-friendly upload form for authenticated users
- adding user login and permissions
- adding pagination and search features
- allowing file-size and MIME validation
- adding categories and tags
- creating a more advanced responsive design
- deploying the project to a hosting platform
